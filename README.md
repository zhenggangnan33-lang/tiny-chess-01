A tiny chess engine for the [tiny-chess-01 bounty](https://make.fun/c/tiny-chess-01) on make.fun. The whole engine packs into `main.py` (4,081 bytes, under the 4,096 cap).

## Design

- 0x88 board, int-packed moves, Zobrist hashing.
- Negamax alpha-beta with iterative deepening and a **total node budget** of 200,000 nodes/move (deterministic — no wall clock), so an 8-game final fits the 1800s limit.
- **Incremental evaluation**: MG/EG scores, phase, bishop counts and king squares are maintained in make/unmake, so the eval is a single tapered lookup (~59k nodes/sec).
- Tapered eval: material + formula piece-square tables + bishop pair + king pawn-cover + tempo.
- Search: transposition table, killers (2/ply), MVV-LVA ordering, PVS, LMR, guarded null-move pruning, futility pruning, check extension, quiescence (captures + evasions in check, stand-pat + delta pruning), repetition via path set + game history.
